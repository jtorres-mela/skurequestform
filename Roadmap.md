# SKU Request Form Roadmap


## New Features
- Notifications when requests are made - Who do we notify? How?
    - Notifications when anything is updated
    - Toggle for notifications
    - Batch notification options
    - Optional field for addtional emails to notify

    - When a request is created
        - Original requester, Program Management
    - When a SKU revision is made
        - Original requester, Program Management, Webcontent
    - When a SKU is added to a request (optional)

    - Integrate with email provider when deploying

- Canada-specific product title, short description, long description
- Facet/refiners - How do we add those to requests?  EU typically submits their facet/refiners with SKU requests
- Categories
- Change list filters to be based on Due Date, not sprint
- 'Show up-to-date version' for each SKU request that shows all current data for a SKU alongside the preview window
- Pull down Smartling translations once they become available
    - For 1.0, manual check button to identify if translations are available
- SKU tags ('In progress, Blocked, Buildout Complete', etc.)
- Option to toggle live SKU preview
- If multiple SKUs submitted at once, allow live preview to display any one of them instead of just the first one
- Copy data from one market to another
- Required fields (SKU Number, name, etc).
- Clear error messaging when submitting SKUs
- Checkmark to verify that field information is correct (spell checking, etc.)
- Work request number in request creation is required
- Download SKU information directly
- Increased messaging for fields
